Управление SSL (Let's Encrypt Certbot)

Выпуск сертификата требует, чтобы домен был направлен на этот сервер и порт 80 был свободен.

Маскировка панели (Сайт-заглушка)

Заглушка отображается всем, кто переходит по основному адресу сервера без секретного пути.

Для типа «Проксирование» укажите полный URL сайта с http/https. Для «Локальный шаблон» укажите название шаблона (по умолчанию: company_landing).

Мультиплексирование клиентов (Mux)

Мультиплексирование позволяет передавать несколько виртуальных соединений в одном TCP-канале, снижая задержку при установке связи (handshake). Не рекомендуется для высокоскоростной загрузки больших файлов.
